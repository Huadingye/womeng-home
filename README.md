# 我萌首页 · 第三版

打开 `index.html` 即可查看。局域网预览可在本目录运行 `python -m http.server 8892 --bind 0.0.0.0`，本机访问 `http://127.0.0.1:8892/`，同一局域网设备访问本机局域网 IP 的 `8892` 端口。

- 公告每4.8秒自动轮播。悬停、聚焦、打开弹层、滚出可视区、页面隐藏时暂停计时；公告栏不显示计数或暂停控件。
- 人物卡可向任意方向拖拽甩出；短拖回弹，Escape取消。键盘聚焦卡组后可按方向键、空格或Enter。卡片外可以正常滚动页面。
- 四张完整人物卡预先渲染并解码头像，整张卡递补，不在丢卡结束时替换头像或文字。所有层都使用同一套皮肤。
- 头像、昵称、性别、语音条、项目标签、收藏书签、指定入口形成固定卡片结构。皮肤扩展约定见 `SKINS.md`。
- 首页点单纸券只显示「系统派单」「我要点单」。进入后保留项目8折不指定与项目全价指定的规则，不设置个人价格。
- 系统派单打开独立式二级表单，服务、性别、时长、开始方式和接单范围从初始状态就全部显示；各选择项使用与控件同宽、圆角分离的奶白下拉菜单，选项尺寸贴合表单控件，服务切换时更新对应时长 SKU。性别默认「不限」，开始方式默认「现在开始」，接单范围默认允许重复接单，预约时间不能早于当前时间。表单沿用首页背景、奶白卡纸纹样、项目插画与统一线稿图标；下单区上方汇总已选条件并直接显示优惠与注意事项，下单按钮占满宽度。
- 「我的」现在是独立的一页式个人中心，而不是收藏弹层：未登录状态先展示账号入口，老板端优先展示钱包区域，其次是订单状态、收藏空状态和常用功能；入口使用当前首页的全局背景与字体，返回后恢复首页 Tab。
- 首页头牌卡片主体、我要点单列表、新人报道卡片和收藏列表中的陪玩行都可以进入 `companion-profile-preview.html?person=昵称`；个人主页按概念图排成大幅电子闪卡、身份信息、个人语音介绍、礼物橱窗、游戏时刻和底部收藏/立即点单/聊一聊操作栏。页面会按昵称动态展示头像、性别、可接单项目和语音文案，返回按钮回到来源页。
- 个人闪卡支持双击浮起与轻微旋转，收藏按钮同时存在于闪卡身份区和底部操作栏，两个入口保持同一收藏状态。
- 实际各项目价目尚未提供，当前价格显示「待配置」，不会生成或提交虚构金额。
- 新人报道为三张简洁小卡，点击进入该人物的项目选择。更多入口显示新人列表。
- 全站只有一层固定装饰背景。正文使用霞鹜文楷屏幕阅读版，标题使用站酷快乐体，字体与图片均保存在本地。
- 顶部主视觉使用粘性固定层，不随正文上下移动；正文元素上滑进入首图区域时，首图逐渐浅色隐退，回到页面顶部时恢复。首页不再显示口号。
- 从顶部向下滚动经过阈值后，页面自动吸附到公告栏顶部；向上回滚经过阈值后吸附回页面顶部。
- 公告和下面的卡片、点单纸券、新人报道在同一页面滚动流里一起移动，没有独立的内部滚动区域。首次下滑即使越过吸附点，也会回到公告栏顶部；公告到顶后禁止继续向下滚动，向上可返回首屏。首图淡出且位于公告后方，不会覆盖公告。
- 页面禁用横向滚动，卡片仍可在卡组区域内向任意方向甩出。
- 底部 Tab 挂在页面根层，固定在移动视口底部，不参与正文滚动；安全区由导航自身处理。

这是首页展示原型。人物、性别和新人资料均为示例数据，没有真实订单、支付、账户或已上传语音。收藏保存在当前浏览器。

`style.css` 为基础样式，`theme.css` 为当前主题，`app.js` 维护数据与交互。`preview-mobile.png` 为新版截图，`throw-preview.gif` 为实际浏览器丢卡录制帧。

图片与字体来源记录在 `assets/provenance.json`。新头像由 Right Code 生成，原卡面与品牌字标来自用户项目。新增两套字体以 SIL OFL 1.1 发布，许可证在 assets 内。当前字体为页面字符子集，新增昵称或公告时应重新生成子集，未覆盖字符会使用系统后备字体。
